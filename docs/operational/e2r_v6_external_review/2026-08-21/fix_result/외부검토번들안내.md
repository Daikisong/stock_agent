## clean PR과 raw 자료의 경계

clean PR에는 `output/**`, `data/cache/**`, raw claim provenance, source/fact checkpoint 전체, collaboration request/response 원문, 기사·리포트 전문과 archive를 넣지 않는다. PR #5와 legacy source branch는 raw 검토 reference로만 유지하며 현재 병합 대상이 아니다.

Gate 1 동안 source corpus, fetch ledger, 36 documents, 2,190 facts와 claim-fact links가 원본과 byte-identical했다는 결과는 compact receipt로 보존한다.

이 번들의 000660 테스트 범위는 **tracked-receipt consistency verification**이다. clean PR에는 996개 fact 원장과 source checkpoint 원문이 없으므로, clone만으로 70.2와 Stage 2를 원천부터 다시 계산할 수 있다는 뜻이 아니다. raw replay가 필요하면 별도 저작권·용량 정책을 통과한 redacted fixture가 추가돼야 한다.

- 7개 component memo 원문
- 21개 Judge 결정 원문
- 7개 final component 결정
- Business model / Red Team / synthesis / Supervisor
- saturation A/B/Independent와 certificate

- 동일 입력 무변동 증명

제외한 14,370개 artifact의 상대 경로·크기·SHA-256·분류는 `external_artifact_receipt.json`에 있다. archive를 새로 만들거나 GitHub Release/LFS에 올리지 않았고 publication status는 `NOT_PUBLISHED`다. repository 내부 gzip을 전제로 하는 복원 스크립트도 clean PR에서 제외했다.

## 해시 검증

원본 branch와 clean PR의 전체 파일 분류는 `clean_merge_payload_manifest.json`에 있다. 기준 원본과 copy-on-write source/fact 불변성은 `current_fact_roster_receipt.json`, `current_request_response_audit.json`, `identical_rerun_audit.json`에 있다. clean branch 테스트와 Git payload 검증 결과는 `clean_merge_verification.md`와 `full_test_receipt.json`에 있다.

`full_test_receipt.json`의 7,204개 결과는 초기 branch 내부 역사적 영수증이다. 독립 검수 수정 후 raw 없는 clean checkout의 7,210개 결과와 skip 사유는 `clean_merge_verification.md`를 우선해서 본다. 최종 독립 환경 판정은 GitHub PR checks가 기준이다.

## 주의

collaboration envelope의 `agent_surface=CODEX_COLLABORATION_SUBAGENT`는 bridge schema의 고정 transport label이다. 이번 마무리에는 새 subagent를 spawn하지 않았고, root가 schema 검증을 통과하는 응답을 직접 작성했다. 해당 사실은 `current_request_response_audit.json`과 final review에 기록한다.
